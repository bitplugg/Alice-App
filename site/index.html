Alice-App

Гайд: как подружить Яндекс Станцию Лайт с Alice-App — нативная Android-панель на Jetpack Compose (Material 3 Expressive): свет RGB на кольцах колонки, звук, пакеты, USB-OTG, консоль и журнал событий.

⬇ Скачать APK GitHub-репозиторий

Что умеет

💡 СветЗаливка 3 LED-колец любым цветом, палитра, hue-слайдер, яркость, зоны (все / 1 / 2 / 3), «погасить», анимации прошивки.
📦 ПакетыПоиск, установка, удаление через yse, журнал установки.
🔊 ЗвукФайлы /data/sounds, потоки по URL, громкость, чайм при включении.
🔌 USB / OTGHost-режим, автозапуск OTG, диски, звуковые карты, маршрут звука (колонка ↔ USB-аудио).
🖥 СистемаАптайм, память, диск, root, ADB/SSH, OTA; логи dmesg/yse/api; reboot.
⌨ Консольshell на колонке и на телефоне (Shizuku, uid shell).
🔔 Журнал событийОпрос: 5 с открытая панель / 15 мин фон (WorkManager). Оффлайн, USB, пакеты → уведомления, без сервера.
🧩 ВиджетыGlance: LED-палитра + «погасить», громкость, кнопки-ссылки на вкладки.
🔄 АвтообновлениеПроверка GitHub Releases: скачивание через DownloadManager → системный установщик.

Установка — 4 шага

Шаг 1 · SSH на колонку 
ssh -p 2222 root@192.168.1.20

«192.168.1.20» условно — поправь на свой IP Станции Лайт. Брать IP: смотри в настройках роутера v1-панели или в дампе DHCP.

Шаг 2 · Поставить бэкенд На колонке (из корня репозитория): 
sh speaker/install.sh
mkdir -p /data/opt/alice/cgi-bin
cp speaker/api.sh /data/opt/alice/cgi-bin/
cp speaker/lighttpd.conf speaker/S96alice /data/opt/alice/
/data/opt/alice/S96alice start

lighttpd слушает порт 8080.

Шаг 3 · Установить APK

Скачай последний APK на телефон и установи (Android 10+; разрешить установку из браузера/файлов).

Шаг 4 · Подключить

Приложение → онбординг: IP колонки → «Подключиться» → (PIN не обязателен — панель сама откроется; можно задать PIN, чтобы закрыть панель). Всё.

FAQ

RGB не светит?
В Debug-экране нажми «Прогнать тест» — либо a=rgb.test: каждая зона мигнёт по red→green→blue. Если мигает по CGI, но не из приложения — проверь, что api.sh свежий (v1.2).

v1 и v2 вместе живут?
Да — applicationId другой (dev.bitplugg.aliceapp.v2), ставятся рядом.

Данные?
Всё локально: DataStore на телефоне, журнал /data/opt/alice на колонке. Никаких серверов и облаков.
